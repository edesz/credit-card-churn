Credit Card Churn Modeling and Insights

Supporting Data-Driven Targeting of Credit Card Customers at Risk of Churning

Welcome

Welcome to our team’s analysis of a client’s credit card customer churn data!.

Our Task

We worked with the manager of the credit card division at a full-service bank to develop a predictive model of credit card customer churn from raw customer data, in order to address the client’s issue of observed growing churn at the bank. These predictions would have to be used by the client and the client’s management team to facilitate data-driven customer retention interventions.

Throughout this project, our team used the PyData stack for scientific computing in Python, which consists of tools for performing data analysis, data visualization, statistical inference, machine learning and interactive computing.

Our Team’s Approach

In order to complete this task, we divided this project into the following five steps

  1. Project Scoping
    • we used the CMU Data Science scoping guide to scope out the project
    • we used the provided historical customer data to quantify the impact of credit card customer churn at the bank by estimating business metrics relevant to the banking sector
    • we determined that our team could deliver value to the client by developing a predictive Machine Learning (ML) churn model to proactively target at-risk customers
  2. Exploratory Data Analysis
    • we analysed the raw customer data using Pandas and extracted insights into and hypotheses about the bank’s credit card customer behaviour and developed hypotheses
    • we used these in the next step to develop predictive ML models
  3. Machine Learning Development
    • based on the outputs of our data analysis, we extracted predictive ML features from the raw customer data
    • we trained ML models to predict customer churn, performing model validation, evaluation and inference using Scikit Learn and XGBoost with MetaFlow for orchestrating model development
    • we used predictions of the best ML model to estimate net savings and combined this with our model’s predicted probability of churn to segment the customers in the raw data and make targeting recommendations per customer segment
  4. Data Validation
    • we developed a data model to validate the raw customer data for use in ML development
    • we used the Pandera data validation framework to develop the data model
  5. Unit Testing
    • we wrote unit tests with the PyTest framework to test the functionality of the custom Python modules that our team developed to implement steps 1. to 4. above
    • we consolidated our unit tests under the tests folder on our team’s Github repository
